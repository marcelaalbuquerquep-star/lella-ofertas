# lella-ofertas

Lista pública de ofertas da **Lella Beauty · Achadinhos de Beleza**, gerada automaticamente pelo robô.
O painel da Lella Beauty lê o arquivo `feed.js` pra receber ofertas novas e preços atualizados.

Só contém informação que já é pública (produto, preço, foto e link de compra). Nenhuma chave ou dado pessoal.
